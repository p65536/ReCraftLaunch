# ReCraftLaunchの更新履歴 {#release_notes}

## 1.0.1 - 2026-11-18

- **追加**
  - 日英のオフラインマニュアルにReCraftLaunchの更新履歴ページを収録。
- **改善**
  - コマンドの保存時に `Link` が相対パスと判定された場合、警告にコマンド名、修飾キーの組み合わせ、入力した `Link`、原因候補を表示。警告を閉じると該当する `Link` 欄にフォーカスが移り、編集中の内容は保持される。
  - コマンドの起動に失敗した場合、コンソールにコマンド名、起動時の修飾キーの組み合わせ、展開後の `Link`、作業フォルダ（`WorkDir`）を表示。別名経由でも呼び出し元のコマンド名と修飾キーの組み合わせが表示される。
- **修正**
  - コマンド編集画面を開くと、フォーカスのない欄は長い値の先頭を表示。Modifierの切り替えやファイルのドロップで値が入れ替わった欄も先頭から表示。最初にフォーカスされた欄と、Tabやアクセスキーで移動した先の欄では、Windows標準のダイアログと同様に全文を選択し、長い値の末尾を表示。
