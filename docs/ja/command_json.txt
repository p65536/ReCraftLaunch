====================
 commands.jsonの形式
====================

commands.jsonは、登録コマンドを保存するJSONファイルです。
このページは、ファイルを直接編集する場合の形式と解釈を説明します。
画面から登録・編集する手順は `ユーザーマニュアル <./index.html>`_ 、操作一覧は `操作一覧 <./commands.html>`_ を参照してください。

保存先と反映
============

使用する設定保存先のcommands.jsonを編集します。
既定の保存先はアプリ内のsettingsフォルダで、「AppDataフォルダ」を選んでいる場合は ``%APPDATA%/ReCraftLaunch`` です。
手動編集後はreloadで登録内容を再適用します。

.. _json-load-errors:

読み込みエラー時の動作
======================

commands.jsonの構文・形式・コマンド名に問題がある場合や、ファイルを読み取れない場合はエラーを通知します。
起動・reloadのエラー内容は、``Ctrl+F10`` でコンソールを開いて確認できます。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 読み込む場面
     - エラー時の動作
   * - アプリの新規起動
     - JSON登録なしで起動を続けます。組込コマンドと、正常に適用できるcustom.pyの独自設定は使用できます。前回起動時の正常なJSONを自動復元することはありません。
   * - 起動後のreload
     - 読み込み失敗前に適用されていたコマンド・キー・独自設定を保持します。直前の正常な登録でコマンドを引き続き実行できます。保持されるのは起動中の状態で、ディスク上のJSONは修正・復元しません。
   * - コマンド一覧・編集画面
     - ディスク上のJSONをそれぞれ読み直します。一覧の読み込みに失敗するとエラーを表示して一覧を開きません。編集画面の読み込みに失敗すると、画面を開けても保存は拒否します。元JSONと入力内容を保持します。

reload失敗後に旧コマンドを実行できても、一覧・編集には現在のファイルを使います。重複名やJSON構文エラーが残っていれば、一覧表示・編集画面からの保存はできません。
これは、手動編集したファイルを古い登録内容で上書きしないためです。
ファイルが存在しない場合は読み込みエラーではなく、JSON登録なしとして扱います。

重複名やJSON構文・形式の問題は、commands.jsonをテキストエディターで直接修正してください。読み取れない場合は保存先とアクセス権を確認してください。
修正後にreloadし、一覧・編集画面を開き直します。読み込み失敗で保存が禁止された編集画面は、ファイルを直した後も開き直す必要があります。

コマンド名と起動操作
====================

最上位のキーがコマンド名です。コマンド名は大文字小文字を区別せず、小文字で管理します。
同じcommands.json内で名前が重複すると、読み込みエラーになります。完全に同じ名前のほか、``Tool`` と ``tool`` のように ``lower()`` で小文字化した結果が同じ名前も対象です。
エラーには重複した名前が表示されます。一覧表示は中止し、編集画面からの保存も拒否します。ファイルを直接修正してからreloadしてください。
セミコロン（``;``）はコマンド名と引数の区切り文字なので、コマンド名には使用できません。
空白文字は前後・中間を問わず使用できません。スペース、タブ、改行、全角空白、ノーブレークスペースなど、Pythonの ``str.isspace()`` が真となる文字が対象です。
``foo``・``foo_bar``・``foo-bar`` は有効ですが、`` foo``・``foo ``・``foo bar`` は不正です。
空欄コマンドはキーを ``""`` として登録できます。空白文字だけの名前は空欄コマンドではなく、不正です。
1つのコマンドに、次の4通りの起動操作を別々に指定します。

.. list-table::
   :header-rows: 1
   :widths: 25 35 40

   * - JSONのキー
     - 編集画面のModifier
     - 実行するキー
   * - target
     - None
     - Enter
   * - on_ctrl
     - Ctrl
     - Ctrl+Enter
   * - on_shift
     - Shift
     - Shift+Enter
   * - on_ctrl_shift
     - Ctrl+Shift
     - Ctrl+Shift+Enter

設定例
======

次の例は、サンプルと同じくnpでメモ帳を起動し、空欄コマンドからnpを参照します。
npにはCtrl+Enterで指定したフォルダを開く操作を追加しています。パスは利用環境に合わせてください。

.. code-block:: json

    {
      "np": {
        "target": {
          "link": "notepad.exe",
          "args": "",
          "workdir": "",
          "view_mode": "normal"
        },
        "on_ctrl": {
          "link": "C:\\Documents",
          "args": "",
          "workdir": "",
          "view_mode": "normal"
        }
      },
      "": {
        "target": {
          "link": "np"
        }
      }
    }

各起動操作の項目
================

.. list-table::
   :header-rows: 1
   :widths: 20 20 60

   * - JSONのキー
     - 編集画面の項目
     - 内容
   * - link
     - Link
     - 必須。プログラム・ファイル・フォルダ・URL、または別の登録コマンド名。
   * - args
     - Args
     - 任意。起動先へ渡す引数文字列。省略時は空です。
   * - workdir
     - WorkDir
     - 任意。作業フォルダ。省略時は空です。
   * - view_mode
     - ViewMode
     - 任意。normal（通常）・minimized（最小化）・maximized（最大化）。省略・欠損時は通常です。

画面の表示名はArgs、JSONキーは ``args`` です。値は配列ではなく1つの文字列です。

Linkのファイル・フォルダは絶対パスで指定します。実行ファイル名（例: ``notepad.exe``）、登録名参照、URL、展開後に絶対パスになる環境変数も使用できます。``tools\tool.exe``、``.\tool.exe``、``..\folder``、``\folder``、``C:folder`` のような相対パスは、WorkDirの指定や実在の有無にかかわらず拒否します。
JSONに相対Linkを記述しても読込み・reloadは成功します。実行時に、選択した操作の別名参照・環境変数・マクロを解決した後で拒否し、コンソールに登録名とLinkを含むエラーを表示します。所在フォルダ・基点置換も同じ扱いです。他の登録や選択していない修飾操作は実行を妨げません。Args内の相対パスは制限しません。
GUIでは保存前に警告して拒否し、入力内容と元ファイルを保持します。実行時引数で起動先が決まる ``%param%`` で始まるLinkは実行時に最終判定します。F12は実行せず、相対表記を含む終端Link文字列をそのままコピーします。

絶対パス全体を一組のダブルクォートで囲んだLinkも指定できます（JSONの値の例: ``"\"C:\\Program Files\\Tool\\tool.exe\""``）。別名・環境変数・マクロの解決後に外側の一組だけを扱い、通常起動・所在フォルダ（既定のShift+Enter）・基点置換・WorkDir自動決定で同じパスを使います。引数はLinkに含めずArgsへ指定します。F12は引用符も含む終端Linkの原文をコピーします。

WorkDirを指定した場合は、その指定を優先します。別名参照では、参照経路で最初の空でないWorkDirを使います。未指定の場合は、実行時にLinkの環境変数・マクロを展開した後、そのパスが実在するファイルなら親フォルダを作業フォルダにします。存在しないパス、実体を特定していない実行ファイル名だけのLink、フォルダ、URLでは自動設定せず、従来の未指定時の動作を使います。

WindowsパスはJSONの規則に従い、``C:\\Programs\\Tool\\tool.exe`` のようにバックスラッシュを二重にします。
起動操作は0件でも登録できます。例えば ``{"disabled": {}}`` は有効です。JSON直接編集では ``{"": {}}`` も許容します。
同名の組込コマンドよりJSON登録が優先されます。例えば ``{"about": {}}`` は、名前を入力しても別名から参照しても何も実行せず、同名の組込コマンドへは戻りません。キー割当による組込機能の直接呼出しには影響しません。
修飾操作を省略すると、configの「修飾キーの既定動作」に従います。
コマンド個別の修飾操作が登録されていれば、そちらが優先されます。

別コマンドへの参照
==================

linkに別の登録コマンド名を指定すると、その起動先を参照できます。
参照元では押したCtrl／Shiftに応じて操作を選びますが、参照先では常に ``target`` （通常操作）を使い、参照元のCtrl／Shift修飾状態は引き継ぎません。
例えば参照元の ``on_ctrl`` が別コマンドを指す場合も、参照先の ``on_ctrl`` ではなく ``target`` を実行します。
呼び元に作業フォルダの指定があれば優先し、なければ参照先の設定を使います。
表示モードは参照元の指定を使います。参照元で省略した場合は通常となり、参照先の表示モードは継承しません。
循環するコマンド参照は作らないでください。実行時に循環を検出すると、その実行を中止し、コンソールに ``a → b → a`` のような参照経路を表示します。

引数
====

メイン入力欄は ``名前;Windows形式の引数文字列`` です。最初のセミコロンだけで分けます。
名前部分だけの前後空白を無視して登録コマンドを先に検索し、同名のOS実行ファイルへは回りません。登録名自体に空白は使用できません。履歴用の入力原文と、セミコロン以降の引数原文は変更しません。
通常の複数引数は ``名前;引数1 引数2``、空白を含む引数は ``名前;"引数 1" 引数2``、空文字列は ``""`` と入力します。
例えば ``np;"Z:\Temp\test.txt" -Y=3`` は ``"Z:\Temp\test.txt" -Y=3`` をそのまま渡します。
2つ目以降のセミコロンも保持し、``名前;one;two`` は ``one;two`` を渡します。直接入力したURLは区切らず全体を扱います。

JSONのargsは従来どおり単一の文字列です。引用符・空白・バックスラッシュを再整形せず、同じ文字列をメイン入力から指定した場合と一致します（JSON上の引用符・バックスラッシュはJSONの規則でエスケープします）。
実体パス・別名参照とも、args内に ``%param%`` があればその位置へ入力文字列を挿入し、なければ固定argsの後ろへ空白1つで追加します。入力がなければ余分な空白を追加しません。
別名連鎖でも参照先の固定args、参照元の固定args、入力引数の順を保ち、各文字列の内部表記を変更しません。
引用符の解釈は起動先に委ねます。固定Argsの環境変数・``%%`` の展開は従来どおりですが、挿入された入力文字列を再展開しません。

画面から保存した場合
====================

画面から保存すると、登録済みの起動操作にはlink・args・workdir・view_modeを保存します。
省略されていたargs・workdirは空文字、view_modeはnormalで補います。未登録の修飾操作は追加しません。
読み込むだけではファイルを書き換えず、保存内容が読込済みの内容と同じなら書込みを省きます。

保存時は同じフォルダの一時ファイルへ書き、成功後に置換します。失敗した場合は元のファイルを保持します。
空欄コマンドのキーは ``""`` です。編集画面ではNameを固定し、一覧からの削除はできません。
GUI保存時は空欄コマンドに少なくとも1つのLinkが必要です。名前付きコマンドは操作0件でも保存できます。
GUIはArgsの前後空白も保持します。
GUIでは名前の空白文字を暗黙に取り除かず、保存時にエラーを表示し、入力内容と元ファイルを保持します。
セミコロン・空白文字を含む名前は、起動・reloadでは読込エラーになります。ただし、名前の重複がなく、JSON構文と起動操作の形式が正しい場合は、その不正名を一覧で確認・削除できます。その名前の複製はできません。重複名があるJSONは一覧自体を開けないため、ファイルを直接修正してください。
commands.jsonから手動で削除した場合も、自動で補完・復元しません。
一覧には未登録でも空欄コマンドの編集入口を常に表示します。表示だけでは ``""`` の登録を追加せず、編集画面で保存したときに登録します。
