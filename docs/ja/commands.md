# 操作一覧

画面別のキー・マウス操作と、名前を入力して実行する組込コマンドをまとめています。
使い始め方・機能説明・設定手順は、F1で開く「ユーザーマニュアル」を参照してください。
以下は標準の割り当てです。`custom.py`で変更した場合は、その割り当てが優先されます。

メイン入力は`名前;引数1 引数2`、空白を含む引数は`名前;"引数 1" 引数2`です。最初の`;`だけが区切りで、以降のセミコロン・引用符・空白・バックスラッシュは保持します。直接URLは全体を扱います。

## メイン入力欄

| 操作 | キー・入力 | 条件・補足 |
|---|---|---|
| コマンドを実行 | Enter | 最初の`;`以降のWindows形式引数文字列をそのまま渡す |
| 修飾操作を実行 | Ctrl+Enter／Shift+Enter／Ctrl+Shift+Enter | 個別の登録、なければ「修飾キーの既定動作」に従う |
| 候補を閉じる／入力クリア／コンソールを閉じる／非アクティブ化 | Esc | 候補表示中、入力がある場合、空欄でコンソール表示中、それ以外の順に処理 |
| 候補の共通部分を補完 | Tab（既定） | 自動補完が有効で候補がある場合のみ。config →「入力オプション」で入力クリアに変更可能 |
| 空白を挿入 | Space（既定） | 同じく補完に変更可能。候補操作には自動補完が有効で候補があることが必要 |
| 入力中の登録コマンドを編集／コマンド一覧を開く | Ctrl+E | 入力ありなら編集、空欄なら一覧 |
| 新規コマンドを登録 | `new` を実行 | [コマンド編集画面](#コマンド編集画面)を参照 |
| 設定メニューを開く | Ctrl+S | 入力文字列と履歴を保持 |
| ログ用コンソールの開閉 | Ctrl+F10 | 本体の組込機能。開くとコンソールへフォーカスを移す |
| ローカルヘルプを開く | F1 | 未配置なら配置方法を表示。入力・選択を保持 |
| 登録先のLink文字列をコピー | F12 | JSON登録の通常操作・別名連鎖の終端Linkが対象。OS検索・絶対パス化・実在確認なし。結果によらず入力終了・非アクティブ化・履歴追加なし |
| 入力全体を指定先へ渡す／プロパティを表示 | Alt+Enter／Ctrl+Alt+Enter／Shift+Alt+Enter／Ctrl+Shift+Alt+Enter | config →「Alt+Enterの動作」で4キーを独立設定。プロパティ関連は通常Alt+Enter専用。登録コマンドのModifierとは別。すべて既定の無効時は入力・選択・フォーカスを保持。有効時は入力終了。履歴追加なし。フォーカス移動は起動先に委ねる |
| 入力中の候補を履歴から削除 | Ctrl+K | 履歴を利用している場合 |
| ファイル・フォルダのコンテキストメニュー | Ctrl+\（106配列）／Ctrl+/（101配列） | 最初の`;`より前の実在パス。全体を囲む引用符一組も可。対象なし・空欄・名前だけなら入力・選択・履歴を保持 |
| 起動先から新規コマンドを登録 | ファイルをメインへドロップ | 保存前に編集画面で確認 |
| メインを呼び出す | config →「ホットキー設定」で設定したキー | 同画面で呼び出し／切替動作を選択 |

## 組込コマンド

登録名は小文字です。入力・実行時は大文字・小文字を区別しません。

| 入力 | 動作 |
|---|---|
| `config` | 本体の設定メニューを開く |
| `reload` | 標準機能、JSONコマンド、`custom.py` を再適用。ディスク上のINIを読み直す操作ではない |
| `history` | コマンド履歴の一覧を開く。履歴の蓄積・保存は入力オプションに従う |
| `about` | コンソールへ製品名・バージョン・リポジトリ・配布先と、移植元情報（CraftLaunchの情報）を出力 |
| `quit` | ReCraftLaunchを終了 |
| `new` | 新規コマンドの編集画面を開く |
| `_ra;<起動先> 引数…` | 登録名・EXE・対応する文書の関連付け先を管理者権限で起動。対応範囲はユーザーマニュアルの「管理者権限で起動」を参照 |

## コマンド一覧

| 操作 | キー・マウス | 補足 |
|---|---|---|
| 選択を移動 | 上下、PageUp／PageDown、Home／End | Home／Endでは確定しない |
| 先頭文字が一致する次の項目へ移動 | 文字キー | 1文字で巡回。F単独も同様 |
| 選択項目を編集 | Enter／Ctrl+E | 空欄コマンドはNameを固定して編集 |
| 新規登録 | Insert | 全Modifierが空の編集画面を開く |
| 選択項目を複製 | Ctrl+Insert | 確認なしで保存し、複製先を選択。未登録の空欄行では何もしない |
| 選択項目の削除確認 | Delete | 空欄コマンドは削除不可 |
| 部分一致検索を開始 | Ctrl+F | 大文字小文字を区別しない |
| 検索文字列を追加／末尾削除 | 文字入力／Backspace | 検索中だけ有効。記号も通常の文字として扱う |
| 検索だけを終了 | Enter／Esc | 選択を保って全件表示へ戻る。編集はもう一度Enter |
| 新規登録画面を開く | ファイルをドロップ | 検索中は無効。ドロップだけでは保存しない |
| 一覧を閉じる | Esc／ウィンドウを閉じる | 選択を確定しない。Escは検索中なら先に検索だけを終了 |

検索中は、編集・新規・複製・削除・ドロップを行えません。

削除・複製の保存後にコマンドの反映だけが失敗した場合は、保存済みであることを通知します。削除・複製を繰り返さず、reloadで再反映してください。

## コマンド編集画面

編集画面を開いている間、呼出し元のメイン画面またはコマンド一覧は表示したまま操作を受け付けません。保存・Esc取消後は呼出し元へ戻ります。一覧からの編集・新規登録・ドロップでは一覧へ戻り、一覧をEscで閉じるとメイン画面へ戻ります。
一覧から開く編集画面は一覧の右側に配置し、タイトルバーの上端を揃えます。メイン画面から直接開く場合は、従来どおりメインの下側を優先します。画面端では作業領域に収まるよう位置を補正します。

Nameにセミコロン（`;`）と空白文字（Unicodeの空白を含む）は使用できません。新規ドロップの自動候補からはこれらを除きますが、手入力は自動で削除せず、保存時に検証します。
名前付きコマンドは起動操作0件でも保存できます。空欄コマンドのGUI保存には少なくとも1つのLinkが必要です。

| 操作 | キー・マウス |
|---|---|
| 次／前の欄へ移動| Tab／Shift+Tab。入力欄の文字列は全選択 |
| 択一項目の次／前 | 右／左、Space／Shift+Space。端で巡回 |
| 択一項目を直接選択 | クリック |
| Modifierを直接選択 | Alt+E: None、Alt+C: Ctrl、Alt+S: Shift、Alt+X: Ctrl+Shift |
| ViewModeを直接選択 | Alt+1: 通常、Alt+2: 最小化、Alt+3: 最大化 |
| 各欄へ移動 | Alt+N/L/A/W/V/M |
| 保存／キャンセル | どの欄でもEnter／Esc |

| ドロップ先 | 動作 |
|---|---|
| Name／Link／Args／WorkDir | その欄へ入力。空欄コマンドのNameは変更不可 |
| 入力欄以外 | Linkへ入力 |

## 設定メニュー・入力画面

| 対象 | 操作 | キー・マウス |
|---|---|---|
| メニュー・一覧 | 選択を移動 | 上下、PageUp／PageDown、Home／End |
| メニュー | 決定／戻る | Enter／Esc。ウィンドウを閉じる操作もキャンセル |
| 言語 | Japanese／Englishを選択（次回起動時に反映） | Enterで保存、Escで取消 |
| 入力画面 | 次／前の欄へ移動 | Tab／Shift+Tab |
| 入力画面 | 決定／キャンセル | Enter／Esc |
| 置換元フォルダ一覧 | 編集／追加／削除 | Enter／Insert／Delete |
| 置換元フォルダ一覧 | 順序を変更 | Ctrl+上下 |
| 置換元フォルダ一覧 | 変更を保存／破棄 | 「保存して戻る」／「キャンセル」またはEsc |
| 画面が作業領域より高い入力・編集画面 | 表示をスクロール | ホイール／PageUp／PageDown |

## コンソール

| 操作 | キー・マウス |
|---|---|
| 開閉 | Ctrl+F10。開くとコンソールへフォーカスを移す |
| 閉じてメインへ戻る | Esc／Ctrl+F10／× |
| 1行／1画面スクロール | 上下／PageUp・PageDown・左右。ホイールも使用可能 |
| 範囲選択してコピー | 左ドラッグして離す |
| 単語を選択してコピー | ダブルクリックして離す |
| 全ログを選択 | Ctrl+A。これだけではコピーしない |
| 選択範囲をコピー | Ctrl+C |
| 全ログを選択してコピー | 本文をトリプルクリックして離す |
| ヘルプを開く | F1 |

LF・CRLFの論理行境界はコピー時にCRLFになります。単独のCRは保持し、表示上の折返しはコピーに追加しません。

| ボタンを実行 | クリック／Enter |
| 閉じる／キャンセル | Esc |
